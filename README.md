# Recipe Finder Web Application

A recipe-finding web application developed using AngularJS, HTML, CSS, and JavaScript.  
This project helps users search for recipes based on ingredients they already have, reducing food waste and making cooking easier.

---

## Features

- Search recipes using ingredients
- Simple and user friendly interface
- Dynamic recipe display
- Responsive web design
- Helps reduce food waste

---

## Technologies Used

- HTML5
- CSS3
- JavaScript
- AngularJS

---


## Project Objective

The objective of this project is to provide users with recipe suggestions using ingredients available at home, helping reduce unnecessary food waste.
